## 1.0.0 (unreleased)

The first public release.

- **Inspect Mode.** Inspect any element on any page and pin a note to it, with a category, selector, structural fingerprint and screenshot.
- **Sidebar and table views.** Filter, edit, resolve, delete with undo, jump to the element, and re-pin a note when its element is gone.
- **Notes.** A one-line note callout attached to the element, your own categories (rename one everywhere at once), status filters (Open, Agent, Re-pin, Done) and delete with Undo.
- **Exports.** Excel, PDF, HTML report, CSV, Markdown, JSON, XML, plain text and a ZIP bundle with screenshots. Copy all notes as Markdown, JSON, XML, plain text, Notion, Linear or Jira, or share one note as a GitHub or GitLab issue, or to Slack, Discord, Trello or email.
- **AI agents.** A local MCP bridge for AI coding agents. Several can connect at once, they are read-only by default, and you can send a single note to one agent from the callout.
- **Optional integrations.** Enhance with your own Anthropic, OpenAI or OpenRouter key, and upload to Google Drive.
