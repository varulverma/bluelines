# Changelog

## 1.0.1 — unreleased

First public release (1.0.0 was the Chrome Web Store draft that was sent back for its listing text; the code is the same).


- Inspect any element on any page and pin a note with a category, selector, fingerprint and screenshot.
- Sidebar and table views: filter, edit, resolve, delete with undo, jump to element, re-pin.
- Exports: Excel, HTML report, CSV, PDF, ZIP; copy as Markdown, JSON, XML, Notion, Linear, Jira.
- Local MCP bridge for AI coding agents, several at once, read-only by default.
- Optional Enhance with your own Anthropic, OpenAI or OpenRouter key; optional Google Drive upload.
